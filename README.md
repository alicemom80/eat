# 앱 템플릿 (단어 학습 게임앱 뼈대)

「동물 영어 놀이」에서 동물 내용을 빼고 만든 뼈대예요. 게임 8종, 별·스티커, 부모 메뉴(하루 시간 제한), 시작 화면, 오프라인 저장(PWA)이 들어 있어요.

## 새 앱 만드는 순서
1. 이 폴더를 통째로 복사해서 새 폴더 이름을 앱 이름으로 바꿔요.
2. `js/app.config.js`: 앱 이름, 저장 이름표(`storagePrefix`, 앱마다 달라야 해요), 인사말, 주인공 그림, 잠금 화면, 배경.
3. `js/data.js`: 주제와 단어 (그림 파일 이름, 영어, 한글). 한 주제에 5의 배수로 넣어요.
4. `images/`: 단어마다 `<그림 이름>.webp` (480×480, 투명 배경), 주인공 그림, 미로용 `girl.webp`.
5. `index.html`의 제목 두 곳, `manifest.json`의 이름·설명, `sw.js`의 `CACHE` 이름을 바꿔요.
6. 그림을 넣거나 빼면 저장 목록을 다시 만들어요:
   `python 작업용/동물영어놀이-새그림/update-sw-list.py <앱 폴더>`
7. 숨은그림찾기가 필요하면 `js/scenes.js`를 채우고 `images/scenes/<주제>.webp`를 넣어요. 비워 두면 버튼이 나오지 않아요.

## 고친 뒤에 올릴 때
- 파일을 고쳤으면 `sw.js`의 `CACHE` 번호를 하나 올려야 폰에 새 버전이 들어가요.
- `검수-체크리스트.md`(작성 예정)로 점검한 뒤 올려요.
